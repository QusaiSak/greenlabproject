Explain in detail how edge computing and cloud computing can be used to execute artificial intelligence workloads, particularly large language model inference. Compare on-device inference with remote inference and discuss how the location of computation affects energy consumption, energy efficiency, execution time, CPU utilization, GPU utilization, memory usage, network traffic, and network latency. Explain the complete path of a remote inference request, beginning with the user device generating a prompt, continuing through the network and remote server, and ending when the generated response is returned to the device. Contrast this with an on-device system where the model is stored and executed locally.

Discuss the advantages and limitations of both approaches. For on-device inference, consider limited computational resources, memory capacity, model size, quantization, thermal constraints, privacy, and the absence of network communication. For remote inference, consider powerful GPUs, server-side resources, network latency, data transfer, request processing time, and the energy consumed by both communication and computation. Explain how network conditions can change the relative energy efficiency of local and remote inference.

Discuss model quantization and explain how different quantization levels can change model size, memory requirements, computational workload, execution time, and energy consumption. Explain why reducing model precision may introduce trade-offs between resource consumption and model performance. Also discuss why different models may have different energy characteristics even when they are evaluated using the same prompt and hardware.

Finally, explain how prompt length and output length can influence inference workload. Describe why experiments comparing local and remote LLM inference should control variables such as model, quantization level, prompt length, output length, hardware, number of runs, and network conditions. Explain how measurements such as total energy in joules, energy per output token in joules per token, execution time in seconds, CPU and GPU utilization in percentage, memory usage in megabytes, network traffic in bytes, and network latency in milliseconds can be used to evaluate the energy efficiency and resource requirements of different inference configurations.
